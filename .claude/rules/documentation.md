# Component documentation

- **Metrics** are documented in the generated `documentation.md`; see [`metrics`](metrics.md).
- **Config** is documented in the component's `README.md`, generated with the latest mdatagen release. The pinned mdatagen rejects a `config:` section.
- To generate: add a `config:` section to `metadata.yaml` describing every field, its type and default; add the `<!-- config autogenerated section -->` / `<!-- end config autogenerated section -->` markers to `README.md`; run the latest mdatagen.
- Keep only the `README.md` change. Revert `metadata.yaml` and every other file the latest mdatagen touched or created.
- Above the markers, note the version: `<!-- This is manually generated using version vX.Y.Z of mdatagen; the pinned version does not support the config section. -->`
- Regenerate whenever a config field, type or default changes.
